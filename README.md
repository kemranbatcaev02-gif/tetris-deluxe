# 🎮 Tetris Deluxe

Тетрис на **C++ / SFML 3** с двумя режимами, прокачкой игрока, монетами и магазином скинов.
Красивые анимации, эффекты частиц при очистке линий и градиентный фон.

![C++](https://img.shields.io/badge/C%2B%2B-17-blue)
![SFML](https://img.shields.io/badge/SFML-3.0-green)

## ✨ Возможности

- **Два режима:**
  - **Классика** — играешь, пока не проиграешь. Скорость растёт с числом линий.
  - **Уровни** — набери нужный счёт, чтобы пройти уровень. С каждым уровнем цель и скорость выше.
- **Прокачка игрока:** за очистку линий даётся опыт (XP). Опыт копится и повышает уровень игрока (на каждый следующий уровень нужно всё больше XP: 50, 75, 100, ...).
- **Монеты:** зарабатываются в обоих режимах и за прохождение уровней.
- **Магазин скинов:** 10 стилей блоков — от простых до дорогих переливающихся (радуга, кристалл, золото, космос). Дешёвые стоят мало, красивые — много.
- **Анимации:** тень фигуры (ghost), вспышка и частицы при очистке линий, тряска экрана, всплывающие награды, живой градиентный фон.
- **Сохранение прогресса** в `profile.dat` (монеты, уровень, XP, купленные скины, рекорд).

## 🕹 Управление

| Клавиша | Действие |
|---|---|
| ← → / A D | Двигать фигуру |
| ↑ / W | Повернуть |
| ↓ / S | Ускорить падение |
| Пробел | Мгновенный сброс |
| Esc / P | Пауза / назад |
| Enter | Выбрать / продолжить |

В меню и магазине — стрелки + Enter (в главном меню работает и мышь).

## 🛠 Сборка на Windows (MSYS2 — рекомендую)

Ставим компилятор и SFML 3 одной командой в терминале **MSYS2 UCRT64**:
```bash
pacman -S mingw-w64-ucrt-x86_64-gcc mingw-w64-ucrt-x86_64-sfml
```
Собираем и запускаем (там же, в MSYS2 UCRT64):
```bash
cd "/c/путь/к/проекту/tetris-cpp"
g++ -std=c++17 -O2 src/*.cpp -o tetris.exe -lsfml-graphics -lsfml-window -lsfml-system
./tetris.exe
```
Запускай игру из этого же терминала — нужные `.dll` подхватятся автоматически.

## 🛠 Сборка через CMake

Нужен установленный SFML 3.
```bash
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build
```

## 🐧 Сборка на Linux
Нужен SFML 3 (собери из исходников или поставь из репозитория, если доступен):
```bash
g++ -std=c++17 -O2 src/*.cpp -o tetris -lsfml-graphics -lsfml-window -lsfml-system
./tetris
```

## 🔤 Шрифт
Игра сама ищет системный шрифт (Segoe UI на Windows). Если хочешь свой — положи любой `.ttf` в `assets/fonts/main.ttf`.

## 📁 Структура
```
tetris-cpp/
├── src/
│   ├── main.cpp        # точка входа
│   ├── Game.*          # состояния, ввод, отрисовка, анимации
│   ├── Board.*         # логика поля, коллизии, очистка линий
│   ├── Tetromino.h     # данные фигур и цвета
│   ├── Skins.*         # каталог скинов и их отрисовка
│   ├── SaveData.*      # профиль игрока и сохранение
│   └── Constants.h     # константы и утилиты
├── assets/fonts/       # сюда можно положить main.ttf
├── CMakeLists.txt
└── README.md
```
