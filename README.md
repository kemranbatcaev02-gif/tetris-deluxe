## ✨ Ключевые особенности

- 🌟 **Два игровых режима:**
  - **Классический марафон:** Бесконечная сессия на выживание. Скорость падения фигур плавно ускоряется с каждой зачищенной линией.
  - **Прохождение по уровням:** Наберите целевой порог очков, чтобы открыть следующий этап с возрастающей сложностью.
- 🎖️ **RPG-прокачка игрока:**
  - За зачистку линий начисляется опыт (XP).
  - Накопление XP повышает глобальный уровень аккаунта по экспоненциальной формуле ($50, 75, 100\dots$ XP на уровень).
- 🪙 **Внутриигровые монеты:**
  - Зарабатываются за результативные комбо и завершение уровней.
- 🛍️ **Магазин визуальных скинов:**
  - 10 уникальных стилей тетромино: от классических плоских плиток до премиальных переливающихся стилей (*Радуга, Неон, Кристалл, Золото, Космос*).
- 💥 **Сочные визуальные спецэффекты:**
  - Тень проекции фигуры (**Ghost Piece**) на дне стакана.
  - Вспышка и взрыв сотен анимированных частиц при сгорании рядов.
  - Кинематографичная тряска экрана (Screen Shake) при мощных сбросах.
  - Динамический градиентный фон.
- 💾 **Автономное сохранение:**
  - Все накопленные монеты, открытые скины, рекордный счет и текущий уровень сохраняются в бинарный файл `profile.dat`.

## 🎮 Режимы игры и RPG-механики

### Магазин скинов
В магазине доступны стилизованные шейдерные текстуры блоков:

| Скин | Описание | Особенность |
| :--- | :--- | :--- |
| **Classic** | Традиционная монохромная палитра | Стандартный |
| **Neon** | Яркие киберпанк-контуры | Светящиеся грани |
| **Crystal** | Ледяные стеклянные грани | Полупрозрачные скосы |
| **Gold** | Роскошный полированный металл | Золотой градиент |
| **Cosmic** | Глубокий космический фиолетовый | Переливающийся блеск |
| **Rainbow** | Радужный цветовой цикл | Плавная смена оттенка |

## 🕹️ Управление

| Действие | Клавиши клавиатуры |
| :--- | :--- |
| **Движение влево / вправо** | `←` / `→` или `A` / `D` |
| **Поворот фигуры** | `↑` или `W` |
| **Ускорение падения (Soft Drop)** | `↓` или `S` |
| **Мгновенный сброс (Hard Drop)** | `Пробел` |
| **Пауза / Меню** | `Esc` или `P` |
| **Подтвердить выбор** | `Enter` |

*В главном меню и магазине поддерживается управление как стрелками, так и курсором мыши.*

## 🛠 Сборка и запуск

### Windows (MSYS2 UCRT64 — рекомендовано)

1. Установите компилятор GCC и библиотеку SFML 3 одной командой в консоли **MSYS2 UCRT64**:
   ```bash
   pacman -S mingw-w64-ucrt-x86_64-gcc mingw-w64-ucrt-x86_64-sfml
   ```
2. Соберите и запустите игру:
   ```bash
   cd tetris-deluxe
   g++ -std=c++17 -O2 src/*.cpp -o tetris.exe -lsfml-graphics -lsfml-window -lsfml-system
   ./tetris.exe
   ```

### Сборка через CMake

```bash
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
```

### Linux (Ubuntu / Debian / Arch)

1. Установите зависимости:
   ```bash
   # Arch Linux:
   sudo pacman -S sfml gcc cmake
   
   # Ubuntu / Debian:
   sudo apt-get install libsfml-dev g++ cmake
   ```
2. Сборка:
   ```bash
   g++ -std=c++17 -O2 src/*.cpp -o tetris -lsfml-graphics -lsfml-window -lsfml-system
   ./tetris
   ```

## 🏗 Структура проекта

```text
tetris-deluxe/
├── CMakeLists.txt              # Сборочный сценарий CMake
├── assets/                     # Графические ассеты и шрифты
│   └── fonts/main.ttf          # Пользовательский шрифт (опционально)
└── src/
    ├── main.cpp                # Точка входа в игру
    ├── Game.h / Game.cpp       # Игровой цикл, обработка ввода, анимации
    ├── Board.h / Board.cpp     # Логика стакана, коллизии, сгорание рядов
    ├── Tetromino.h             # 7 канонических форм фигурок тетрамино
    ├── Skins.h / Skins.cpp     # Каталог 10 скинов и их процедурная отрисовка
    ├── SaveData.h / SaveData.cpp # Сериализация профиля в profile.dat
    └── Constants.h             # Физические константы и параметры окна
```
